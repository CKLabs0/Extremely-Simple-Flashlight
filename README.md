# Extremely-Simple-Flashlight

Developed with Kotlin, using modern Android services (Camera2 API, Foreground Services, UMP Consent) flashlight app.
•
Specs:
◦
Flaslight
◦
Adjustable brightness (Android 13+).
◦
S.O.S and Strobe Mode
◦
Emergency screen light
◦
AdMob and GDPR UMP entegration.
•
Kotlin, Android SDK, Material 3, Camera2 API, Google Play Ads SDK.
